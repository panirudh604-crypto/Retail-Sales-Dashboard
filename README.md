# Retail Sales Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze retail sales performance, profitability, customer activity, and regional trends. The dashboard presents key performance indicators and visualizations to help understand business performance.

## Key Metrics
- **Total Sales:** $12.64M
- **Total Profit:** $1.47M
- **Total Orders:** 25K
- **Year-over-Year Sales Growth:** 51.54%

## Key Insights
- **Product Performance:** Technology recorded the highest sales and profit among the three product categories.
- **Order Priority:** Medium-priority orders accounted for the largest share, at 58.89%.
- **Regional Performance:** The dashboard compares sales and profit across regions to highlight differences in regional performance.

## Dashboard Features
- Sales and profit analysis
- Year-over-year sales growth tracking
- Top 10 active buyers and revenue-generating customers
- Regional sales and profitability comparison
- Order priority distribution
- Interactive filters for exploring data

## Data Model
The project uses four tables:

- **Customer:** Customer related information
- **Location:** Geographical information
- **Product:** Product related information
- **Sales:** Transactional data used as the fact table

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
